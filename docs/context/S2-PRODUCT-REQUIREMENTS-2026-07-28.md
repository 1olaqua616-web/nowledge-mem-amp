## 1. 问题陈述：Amp ↔ nmem 关系中缺三样

### P1 缺自治——「我不喊，它就不动」

在 Amp 里，记忆不会自己出现，也不会自己留下。每开一个新会话，过去的上下文不到场；工作中值得留的决定，没有任何东西代劳保存。一切取决于 agent 是否自己想起调用记忆工具、或用户是否开口——用户忘了喊，记忆就断档。

官方对这个状态的定性（FACTS §3 [文档]）：Direct MCP 档 "MCP tools alone do not create autonomy"；Reusable package 档 "Usually guided"。本机现状恰好停在这两档（FACTS §2 [实测]）。缺口论证见 S1 §3.1。

### P2 缺真实抓取——「对话过程正在持续丢失」

在 Amp 里发生的对话从未被真实保存。今天的「存线程」是降级品：存的是摘要，不是对话（save-thread 自述 "must degrade honestly to a resumable handoff"，FACTS §2 [实测]）。会话里的推理过程、决策理由，session 一关就永久丢失——事后想回溯「当时为什么那么定」，只剩一句摘要。缺口论证见 S1 §3.2。

### P3 缺运行时可变——「会话开始后，语境就定死了」

会话开始后，带进来的上下文无法更换。AGENTS.md 是静态文件（S1 §3.3）；session 中途换了任务域、换了服务对象，生效的记忆语境还是旧的，只能改文件、重开会话。

## 2. 成功标准（shipping 后可读可判）

| # | 对应 | 成功标准 | 判定方式 |
|---|---|---|---|
| C1 | P1 | 新会话开场**无需任何人开口**，第一轮即有 nmem 当日上下文（Context Bundle 或 Working Memory）到场 | 开新会话零提示词，首轮内容可见/可被 agent 引用该上下文 |
| C2 | P1 | 安装达成官方 Definition of Done 六条（FACTS §3 [文档]）：host detected / install path / nmem status green / restart confirmed / 新会话内 Bundle 或 WM 可达 / 提示保存第一条记忆 | 逐条走查安装验收清单 |
| C3 | P2 | 任一 Amp 会话的**真实对话原文**（用户与 assistant 双方，非摘要）出现在 nmem 中且可检索；同一会话重复保存不产生副本 | nmem 内搜索该会话原文命中；多次同步后 thread 唯一 |
| C4 | P2 | 会话异常终止（crash/强退）时，已发生的对话仍绝大部分保留在 nmem（最终一致，不要求最后一轮必达） | 中途强杀会话后检查 nmem 中该 thread 的内容完整度 |
| C5 | P3 | 同一会话内可切换生效的记忆语境（space / agent 身份），自下一轮起注入内容随之改变，无需重开会话 | 会话中切换后对比前后到场的上下文内容 |
| C6 | 韧性 | nmem 服务不可用时，Amp 会话完全不受影响（不卡顿、不报错刷屏）；服务恢复后记忆能力自动回来，期间对话不因此永久丢失 | 停掉 nmem 后正常使用 Amp；重启 nmem 后验证同步补齐 |
| C7 | 语境经济 | 记忆注入不显著挤占工作上下文：长会话中注入的常驻成本有上界，不随轮数累积滚雪球 | 长会话（数十轮）末查看上下文中记忆注入的占比与增长趋势 |

C6/C7 不对应单一缺口，是两官方样本跨范式一致的产品级底线（S1 §5 对照记录：降级不缺席、最小面注入；[观察] 其中 C7 在 Amp 语境下比 Antigravity 更尖锐，依据 FACTS §7.5 注入落点语义）。

## 3. 范围

**In-scope（本期）**
- 本机 Amp（CLI/桌面）环境下，兑现 P1/P2/P3 对应的 C1–C7；
- nmem local 模式（本机现状，FACTS §2 [实测]）。

**Out-of-scope（本期明确不做）**
- 历史回填（官方定位属 CLI importer / 单独脚本职责，PI-READING §8 [源码]；connector 只管「新工作保持最新」，FACTS §3 [文档]）；
- 修改 nmem 服务端（以现有 HTTP 合同为既定约束；若 S3 前置实测发现 `source:"amp"` 被服务端拒收，升级为阻塞项回到本节重议）；
- 一包多 host 复用（pi/omp 式，PI-READING §6）。

**待拍板（用户裁决,S3 开工前后均可）**
1. **Orb 支持**：plugin 在 Orb 内运行仅有间接证据（FACTS §5 [实测·间接]）。建议本期列观察项、不承诺 C1–C7 在 Orb 内成立;是否采纳待裁决;
2. **权限门**：abn 有三档权限门,pi 官方完全没有（S1 §5;两样本公开打架的自由变量）。本期是否要,待裁决;
3. **remote nmem 模式**：配置层已支持（FACTS §1 config 解析 [源码]）,本期是否纳入验证,待裁决。
